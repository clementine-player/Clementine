# Showcase album covers

The covers of the showcase library (`showcase-library.tsv`), which the store
screenshots show. Each is a public-domain work from Wikimedia Commons, cropped
to a 600×600 square. The file name is the album's.

| Album | Work | Source |
| --- | --- | --- |
| Gymnopédies (Satie) | Pierre Puvis de Chavannes, *The Poor Fisherman* (1881), Musée d'Orsay | [Commons](https://commons.wikimedia.org/wiki/File:Pierre_Puvis_de_Chavannes_-_The_Poor_Fisherman_-_Google_Art_Project.jpg) |
| Suite bergamasque (Debussy) | Antoine Watteau, *The Embarkation for Cythera* (1717), Louvre | [Commons](https://commons.wikimedia.org/wiki/File:L%27Embarquement_pour_Cyth%C3%A8re,_by_Antoine_Watteau,_from_C2RMF_retouched.jpg) |
| Nocturnes, Op. 9 (Chopin) | James McNeill Whistler, *Nocturne: Blue and Silver – Chelsea* (1871), Tate | [Commons](https://commons.wikimedia.org/wiki/File:James_Abbott_McNeill_Whistler_-_Nocturne-_Blue_and_Silver_-_Chelsea_-_Google_Art_Project.jpg) |
| Goldberg Variations (Bach) | Title page of the first edition, *Clavier Übung … Aria mit verschiedenen Verænderungen* (Balthasar Schmid, Nuremberg, 1741) | [Commons](https://commons.wikimedia.org/wiki/File:Goldberg-titlepage.png) |

Each matches its music: Puvis de Chavannes' still, pale painting is often paired
with the Gymnopédies; Watteau's *fêtes galantes* are the world of Verlaine's
"Clair de lune", after which Debussy named the suite's best-known piece;
Whistler named his night scenes nocturnes after Chopin's form; and the Goldberg
Variations' own title page.

The painters died more than a century ago, and these are faithful reproductions
of two-dimensional works, which are in the public domain.
